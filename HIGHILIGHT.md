### 💻 About Me

I'm a **Full-Stack Developer** who has gone deep into the AI/LLM space. I don't just use AI APIs — I architect end-to-end **Retrieval-Augmented Generation (RAG) pipelines**, build custom SQL query engines that run on live API data, and engineer streaming inference layers via Next.js Edge Functions.

My stack spans premium UI systems (Linear-inspired design, Framer Motion) all the way down to vector databases, embedding models, and re-ranking APIs.

- 🧠 **AI / RAG Engineering**: Pinecone, OpenAI Embeddings, Cohere ReRank, Google Gemini, Grok / LLaMA 3.3 70B
- 🏗️ **Full-Stack Architecture**: Next.js 15 App Router, TypeScript, Firebase, Zustand, TanStack Query
- 🎨 **Design Systems**: Linear-inspired aesthetics, Framer Motion animations, glassmorphism, pixel-perfect clones
- ⚡ **Built for Performance**: Edge Functions, streaming LLM responses, optimistic UI, aggressive caching
